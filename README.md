# Smart Salary Tracker

Smart Salary Tracker helps workers record shifts, overtime, allowances, deductions, and monthly salary summaries from a phone or web browser.

## Use The App

- Web App: https://webdist-puce.vercel.app
- Android APK: https://webdist-puce.vercel.app/SmartSalaryTracker.apk

## Main Features

- Work-time and overtime records
- Night-shift and holiday-pay calculations
- Monthly salary summaries and payslips
- Multiple interface languages
- JSON, CSV, and Excel exports
- Optional Google Sign-In and Google Drive App Data backup

## Privacy

- Basic Mode stores data only in the current browser or device.
- Full Mode uses verified Google OAuth sign-in.
- Browser data is separated by verified Google account ID.
- The app does not store a Google password.
