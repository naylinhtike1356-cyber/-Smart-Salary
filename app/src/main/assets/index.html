* မိမိစက်ရုံ၏ ထမင်းစားချိန်နှင့် နားချိန်များကို စိတ်ကြိုက်ပြင်ဆင်နိုင်ပါသည်။ အလုပ်ချိန်တွက်ချက်ရာတွင် သတ်မှတ်ထားသော နားချိန်များကို အလိုအလျောက် နုတ်ပေးမည် ဖြစ်သည်။

ပင်စင်မဖြတ်သော စက်ရုံများအတွက် 0% ဖြစ်ပြီး၊ ပုံမှန်အလုပ်သမားထည့်ဝင်ကြေးမှာ 4.5% ဖြစ်ပါသည်။

ကျန်းမာရေးအာမခံ၏ %

သတ်မှတ်ချိန်တွင် "ယနေ့ အလုပ်မှတ်တမ်း ထည့်ပြီးပြီလား?" သတိပေးချက် ပေါ်မည်။

• Backup (JSON): ဖုန်းအသစ်ပြောင်းလျှင် သို့မဟုတ် ဖုန်းပျက်လျှင် အချက်အလက်များ ပြန်ယူရန် သိမ်းဆည်းပါ။
• Export CSV / Excel: လစာစာရင်းကို Excel သို့မဟုတ် ကွန်ပျူတာဖြင့် စာရွက်ထုတ်ယူလိုလျှင် အသုံးပြုပါ။
• Restore (Import): ယခင်သိမ်းထားသော JSON ဖိုင်ကို ပြန်လည်သွင်းယူပါက လက်ရှိမှတ်တမ်းများပေါ်သို့ အစားထိုးမည် ဖြစ်ပါသည်။

အလုပ်မှတ်တမ်းအသစ် ထည့်သွင်း/ပြင်ဆင်ပြီးတိုင်း ဖုန်းတွင်း အရန်သိမ်းပေးပြီး Google Drive ချိတ်ဆက်ထားပါက Cloud သို့ပါ အလိုအလျောက် အရန်သိမ်းပေးပါမည်။
