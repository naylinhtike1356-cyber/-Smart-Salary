iPhone မှာ Smart Salary ကို အိုင်ကွန်နဲ့ တပ်ဆင်ကြမယ်

  1. Facebook ထဲက Browser အစား Safari ကို ဖွင့်ပါ။
  2. webdist-puce.vercel.app ကို ဝင်ပါ။
  3. Share — အပေါ်မြားပါသော လေးထောင့်ခလုတ်ကို နှိပ်ပါ။ Safari ပုံစံအလိုက် Menu ထဲမှာ ရှိနိုင်ပါတယ်။
  4. Add to Home Screen ကို ရွေးပါ။ မတွေ့ရင် Edit Actions မှာ ထည့်ပါ။
  5. Open as Web App ရွေးချယ်စရာပေါ်ရင် ဖွင့်ထားပါ။ နာမည်ကို Smart Salary ထားပြီး Add နှိပ်ပါ။

Home Screen က အိုင်ကွန်ကို နှိပ်ပြီး App ကို ဖွင့်နိုင်ပါပြီ။ Google အကောင့်ချိတ်ခြင်းနဲ့ Drive Backup/Restore အတွက် အင်တာနက်လိုပါတယ်။

စက်ပြောင်းပြီး အရင်ဒေတာ ပြန်ယူချင်ရင်

ယခင်စက်မှာ မူလ Google အကောင့်နဲ့ ချိတ်ပြီး Settings → Drive သို့ သိမ်းမည် ကို အရင်နှိပ်ပါ။ iPhone ရဲ့ Home Screen App ထဲမှာ အကောင့်တူနဲ့ ဝင်ပြီး Settings → Drive မှ ပြန်ယူမည် ကို နှိပ်ပါ။ Google အကောင့်ဝင်ရုံနဲ့ ဒေတာအလိုအလျောက် ပြန်မပေါ်ပါ။

Safari နဲ့ Home Screen App မှာ ဒေတာမတူရင် အသစ်တပ်ဆင်ထားတဲ့ App ထဲမှာ အကောင့်ဝင်ပြီး Restore ပြန်လုပ်ပါ။ မူလစက်က ဒေတာကို မဖျက်ပါနဲ့။
